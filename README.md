# Flowtask
Flowtask é uma aplicação web para gerenciamento de projetos baseada em metodologias ágeis como Kanban, Scrum e práticas  de XP. Permite organizar tarefas em quadros visuais, acompanhar o progresso em tempo real e colaborar em equipe, contando com interface moderna, autenticação de usuários e integração com Supabase para armazenamento de dados.
